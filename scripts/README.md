# Scripts

| Script | npm command | Purpose |
|--------|-------------|---------|
| `validate-data.js` | `npm run validate-data` | Parse every JSON file under `data/` — fails fast on invalid JSON. |
| `export-csv.js` | `npm run export-csv` | Export pipeline for designers (see script header for options). |

Run from **repository root** so `data/` paths resolve correctly.
