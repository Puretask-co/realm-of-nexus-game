# Realm of Nexus — Startup Guide

How to run the game locally with the Claude AI features enabled.

---

## One-time setup (do this once, then never again)

### Step 1 — Get a new Anthropic API key

1. Go to https://console.anthropic.com
2. Click **API Keys** in the left sidebar
3. Click **Create Key**
4. Give it a name like `realm-of-nexus`
5. Copy the key — it starts with `sk-ant-api03-...`

> **NEVER share this key with anyone. Never paste it into Discord, chat, or code files.**

---

### Step 2 — Create your `.env` file

1. Open **File Explorer**
2. Navigate to your project folder:
   ```
   C:\Users\onlyw\Desktop\realm-of-nexus-game
   ```
3. Right-click in an empty area → **New** → **Text Document**
4. Name it exactly: `.env` (yes, it starts with a dot — Windows may warn you, that's fine)
5. Open the file with Notepad and paste this **one line**, replacing the placeholder with your actual key:

```
ANTHROPIC_API_KEY=sk-ant-api03-your-actual-key-here
```

6. Save and close.

That's it. The `.env` file tells the proxy server your API key when it starts up.

> Your `.env` file is listed in `.gitignore` — it will NEVER be committed to git or shared.

---

### Step 3 — Install dependencies (if you haven't already)

Open a terminal in the project folder and run:

```bash
npm install
```

You only need to do this once (or after pulling new code that changes `package.json`).

---

## Every time you want to play

You need **two terminal windows** open at the same time. Here's exactly what to do:

---

### Terminal 1 — The Proxy Server (loads your API key, talks to Claude)

1. Open a terminal in your project folder
2. Run:

```bash
node --env-file=.env proxy-server.js
```

3. You should see:

```
[proxy] Realm of Nexus proxy running on http://localhost:3001
[proxy] Forwarding /api/claude → api.anthropic.com/v1/messages
[proxy] Ready.
```

4. **Leave this terminal open.** If you close it, AI features stop working (but the game still runs with fallback text).

---

### Terminal 2 — The Game Dev Server

1. Open a **second** terminal in the same project folder
2. Run:

```bash
npm run dev
```

3. You should see:

```
VITE ready in ... ms
Local: http://localhost:3000/
```

4. The game will automatically open in your browser.

---

## Summary — What each thing does

| What | Command | Port | Purpose |
|------|---------|------|---------|
| Proxy server | `node --env-file=.env proxy-server.js` | 3001 | Holds your API key, forwards calls to Claude |
| Game server | `npm run dev` | 3000 | Runs the actual game in your browser |

---

## Shutting down

- Press `Ctrl + C` in each terminal to stop it.
- You can stop in any order — doesn't matter.

## Troubleshooting

**"ANTHROPIC_API_KEY is not set"**
Your `.env` file is missing or in the wrong folder. Make sure it's in the root of the project (same folder as `package.json`).

**Game works but AI narration doesn't appear**
The proxy server isn't running. Start Terminal 1 first, check it shows `[proxy] Ready.`

**"node: --env-file flag not found" or similar**
You're on an older version of Node. Run this instead:
```bash
# Windows (PowerShell)
$env:ANTHROPIC_API_KEY="sk-ant-api03-your-key"; node proxy-server.js

# Windows (Command Prompt)
set ANTHROPIC_API_KEY=sk-ant-api03-your-key && node proxy-server.js
```

**Port 3000 already in use**
Something else is using port 3000. Either close that app, or change the port in `vite.config.js` (line `port: 3000`).

**Port 3001 already in use**
Change the `PORT` constant at the top of `proxy-server.js` from `3001` to `3002`, then restart the proxy.

## What the AI actually does in-game

| Feature | Where you see it |
|---------|-----------------|
| **AI Dungeon Master** | Short narration lines when entering zones, winning combat, discovering items |
| **Veilkeeper responses** | When you consult a Veilkeeper NPC, their answer is generated by Claude with full game context |

If the proxy isn't running, both features fall back to pre-written static text — the game works either way.

## Where your save files are stored

Every time you save in-game, your progress is written to **two places**:

1. **Browser localStorage** — instant, automatic (cleared if you wipe browser data)
2. **Your Documents folder** — permanent files that survive everything:
   ```
   C:\Users\onlyw\Documents\Realm of Nexus Saves\
       verdance_save_slot0.json       ← Slot 1
       verdance_save_slot1.json       ← Slot 2
       verdance_save_slot2.json       ← Slot 3
       verdance_save_slot0_backup.json ← Auto-backup of Slot 1
   ```

When loading, the game checks the file save first and picks whichever is newer (file or browser). If the proxy server isn't running, saving still works via localStorage only.

You can back these `.json` files up to cloud storage, copy them to another machine, or just keep them as insurance.

## Costs

The game uses `claude-haiku` (the fastest, cheapest Claude model) with a maximum of 120 tokens per response. A typical play session uses only a few cents of API credit.

Anthropic gives new accounts free credits to start. You can set a usage limit at https://console.anthropic.com/settings/limits to cap how much you spend.
